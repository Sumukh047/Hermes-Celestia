# Troubleshooting

**LM Studio offline:** start its local server and verify `http://127.0.0.1:1234/v1/models`.

**No models:** download a compatible model in LM Studio and refresh AI Engine.

**Agent won't run:** choose an LM Studio model in the agent editor.

**Tool blocked:** check the agent's Tools & permissions and autonomy level.

**Hermes not detected:** the GUI/runtime does not depend on the CLI. Install Hermes separately when you want the CLI adapter/inspection layer.
